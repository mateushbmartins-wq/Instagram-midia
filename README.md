# instagram-midia

Artes publicadas no Instagram @mateushmartins_. Repositório público: aqui só entram imagens que vão para o feed.

- `posts/AAAA-MM-DD-tema/1.jpg ... 4.jpg`: lâminas de cada post (o Metricool lê pelo link raw).
- `assets/avatar.jpg`: foto do cabeçalho.
- `modelo/`: as 4 lâminas-modelo (capa, texto, lista numerada, fechamento) e `render.py`, que gera os JPG 1080x1350.

Link de cada imagem para o Metricool:
`https://raw.githubusercontent.com/mateushbmartins-wq/instagram-midia/main/posts/<pasta>/<n>.jpg`
